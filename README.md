## Зміст лабораторної роботи

### 1. Лабораторна робота № 9.1: «Простори імен»
- **Тема**: Створення багатомодульного проєкту C++ із використанням просторів імен (`namespace`) та відокремленням заголовних файлів (`.h`) від файлів реалізації (`.cpp`).
- **Завдання (Варіант 8)**: Обчислення наближеного значення функції $\operatorname{arctg} x$ за допомогою розкладу в степеневий ряд Тейлора:
  $$\operatorname{arctg} x = \frac{\pi}{2} + \sum_{n=0}^{\infty} \frac{(-1)^{n+1}}{(2n+1) x^{2n+1}} = \frac{\pi}{2} - \frac{1}{x} + \frac{1}{3x^3} - \frac{1}{5x^5} + \dots, \quad x > 1$$
- **Структура проєкту**:
  - `var.h` / `var.cpp` — простір імен `nsVar` для глобальних змінних (`x`, `x_p`, `x_k`, `dx`, `e`, `a`, `s`, `n`).
  - `dod.h` / `dod.cpp` — простір імен `nsDod`, обчислення доданку за рекурентним співвідношенням $R = -\frac{2n-1}{(2n+1)x^2}$.
  - `sum.h` / `sum.cpp` — простір імен `nsSum`, обчислення суми ряду з точністю $\varepsilon$.
  - `Lab_09_1.cpp` — головна програма з табличним виведенням значень аргументу, суми ряду, точного значення `atan(x)` та кількості доданків $n$.

### 2. Лабораторна робота № 9.2.1: «Директиви препроцесора та макровизначення (Частина 1)»
- **Тема**: Використання директив умовної компіляції (`#if`, `#else`, `#endif`) та параметризованих макровизначень (`#define`).
- **Завдання (Варіант 8)**:
  $$w = \begin{cases} \max(x^3, (x + y)^2), & z > 10 \\ \min(|x - z|, |x + z|), & z \le 10 \end{cases}$$
- **Структура проєкту**:
  - `macros.h` — макровизначення операцій `SQR`, `CUBE`, `MAX`, `MIN`, `ABS`, виведення `PRINTI`, `PRINTR`, та макровиразів для обох гілок `CALC_W1`, `CALC_W2`.
  - `Lab_09_2_1.cpp` — умовна компіляція однієї з гілок залежно від значення препроцесорної константи `Z`.
